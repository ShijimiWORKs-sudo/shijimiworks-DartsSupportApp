## 推奨確認フロー

1. `npm run start:lan` でMetroを起動する。
2. iPhoneのExpo GoでQRコードを読み取る。
3. `今日` でメニューを作成し、開始、一時停止、再開、完了、結果保存を確認する。
4. Expo Goを完全に閉じ、再度同じプロジェクトを開いてデータが残るか確認する。
5. `フォーム` で動画ライブラリを開き、動画を1本選択して保存する。
6. `ChatGPT用指示文をコピー` を押し、別アプリの入力欄へ貼り付けて内容を確認する。
7. ChatGPT評価文のサンプルをコピーし、`ChatGPT評価を読み込む` から貼り付け、解析、保存する。
8. `改善` で次回の改善点、改善課題、練習候補が表示されるか確認する。
9. `バックアップ` でJSONを生成し、新規テーブルと動画メタデータが含まれるか確認する。

## 問題発生時に記録する情報

- Expo Goに表示された赤いエラー画面のスクリーンショット
- PC側Metroターミナルのエラー全文
- 問題が起きた操作手順
- 使用した起動方式: LAN / Tunnel
- iPhone機種
- iOSバージョン
- Expo Goバージョン
- PCとiPhoneが同一Wi-Fiか
- VPNの有無
- 発生画面
- 再現頻度

## 既知の制約

- 動画本体はSQLiteやバックアップJSONへ含めません。
- Expo Go初期版では写真ライブラリ由来URIをアプリ管理領域へコピーしません。端末状態によって後から動画を開けなくなる場合があります。
- iOSの権限説明文はStandalone Buildでは `app.json` の文言が反映されます。Expo GoではExpo Goアプリ側の権限表示になる場合があります。
